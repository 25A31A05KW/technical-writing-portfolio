# Student Task Manager — Project Documentation

## Overview

Student Task Manager is a simple command-line application designed to help students manage their daily tasks.

Users can add tasks, view existing tasks, mark tasks as completed, and remove tasks.

## Features

The application provides the following features:

- Add a new task
- View all tasks
- Mark a task as completed
- Delete a task
- Exit the application

## Requirements

To run the project, you need:

- A C++ compiler
- C++11 or later
- A terminal or command prompt

## Installation

Clone or download the project source code.

Compile the program using a C++ compiler.

Example:

```bash
g++ main.cpp -o task-manager
